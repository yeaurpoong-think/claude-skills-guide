💡 WHAT IS CLAUDE SKILLS

스킬이 뭔가요?

Anthropic이 Claude Code에 공식 도입한 확장 시스템. .md 파일로 만든 커스텀 명령을 Claude에게 가르쳐서, 특정 분야의 전문가처럼 작동하게 만듭니다.

📦
AI를 위한 npm
스킬 = AI 에이전트의 패키지. npm처럼 원하는 능력을 골라서 설치하고, 필요 없으면 제거합니다.
🔗
오픈 스탠다드
Claude Code뿐 아니라 Cursor, Codex, Windsurf, Gemini CLI 등 주요 AI 에이전트 전체에서 동작합니다.
📁
설치 위치로 범위 조절
스킬을 어디에 설치하느냐에 따라 적용 범위가 달라져요.

🌍 내 컴퓨터 전체에 적용
홈 폴더 안의 .claude/skills/ 에 설치하면, Claude Code를 어디서 켜든 항상 켜져 있어요.

📂 특정 작업 폴더에만 적용
프로젝트 폴더 안에 넣으면, 그 폴더에서만 동작해요.
⚡
슬래시 커맨드로 호출
설치 후 /skill-name 또는 @skill-name 으로 즉시 호출. 배우는 시간 없이 바로 씁니다.

Node.js부터 설치하세요

Claude Code CLI는 Node.js 위에서 동작합니다. 터미널이 아직 낯설어도 괜찮아요 — 아래 설치 파일을 받아서 실행하기만 하면 됩니다.

1
nodejs.org에서 설치 파일 다운로드
nodejs.org 접속 → LTS(권장) 버전의 Windows Installer (.msi) 버튼 클릭 → 다운로드
2
설치 파일 실행
다운로드한 .msi 파일을 더블클릭 → Next를 계속 눌러 기본 옵션 그대로 설치 완료 (체크박스는 전부 기본값 유지 권장)
3
설치 확인
설치 후 PowerShell을 새로 열어서(이미 열려있던 창은 인식 못 함) 아래 명령어로 버전이 뜨는지 확인하세요.
$ node --version
# v20.x.x 처럼 버전이 출력되면 성공
$ npm --version

💻 BEFORE YOU START

이제
터미널을 열어야 합니다

터미널(명령 프롬프트)은 명령어를 타이핑해서 컴퓨터에 직접 지시를 내리는 창입니다. 처음엔 낯설어도 아래 방법 중 하나만 알면 충분해요.

추천
방법 1 — Win + R 단축키
Win + R 키를 동시에 누르세요
작은 실행 창이 뜨면 powershell 입력 후 Enter
파란 창이 열리면 성공 ✅ (검은 창이 뜨면 cmd이니 닫고 다시 시도)
실행
열기(O):
powershell|
확인취소찾아보기
방법 2 — 검색창에서 열기
작업 표시줄 검색창(🔍)을 클릭하거나 Win 키를 누르세요
powershell 입력
Windows PowerShell 앱을 클릭해서 열기 (cmd·명령 프롬프트는 선택하지 마세요)
방법 3 — Windows Terminal (최신 추천)
검색창에 Windows Terminal 입력
없다면 Microsoft Store에서 무료 설치
탭 방식으로 여러 터미널을 동시에 쓸 수 있어요
방법 4 — VS Code 내장 터미널
VS Code가 이미 설치되어 있다면 가장 편해요
상단 메뉴 → Terminal → New Terminal
단축키: Ctrl + ` (백틱)
추천
방법 1 — Spotlight 검색
⌘ Cmd + Space 를 누르세요
검색창에 Terminal 입력 후 Enter
흰색 또는 검은 창이 열리면 성공 ✅
방법 2 — Finder에서 찾기
Finder → 응용 프로그램 → 유틸리티 폴더
Terminal.app 더블클릭
방법 3 — iTerm2 (개발자 추천)
iterm2.com 에서 무료 다운로드
기본 Terminal보다 기능이 풍부하고 다루기 편해요

터미널이 열렸다면 이제 Claude Code를 설치할 차례예요.
아래 설치 가이드를 따라서 명령어를 복사 → 붙여넣기(Ctrl+V / Cmd+V) → Enter 만 하면 됩니다.
⚙️ CLAUDE CODE CLI

Claude Code CLI
설치하기

스킬을 쓰려면 먼저 Claude Code CLI 자체가 설치되어 있어야 합니다. Node.js가 필요하고, 설치 후 로그인 한 번만 하면 끝이에요.

1
Node.js 설치 확인 (v18 이상 필요)
터미널에 아래 명령어를 입력해서 버전이 뜨는지 확인하세요. 안 뜨면 nodejs.org에서 LTS 버전을 먼저 설치해야 합니다.
$ node --version
# v18.0.0 이상이면 OK
2
Claude Code CLI 설치
아래 명령어 한 줄로 전역 설치됩니다. Windows/macOS 동일한 명령어예요.
$ npm install -g @anthropic-ai/claude-code
3
설치 확인
버전이 출력되면 설치 성공입니다.
$ claude --version
2.1.143 (Claude Code)
4
로그인 (최초 1회)
claude 명령어를 실행하면 브라우저가 열리면서 로그인 화면이 뜹니다. Claude Pro/Max 구독 계정으로 로그인하거나, API 키를 쓰려면 아래 명령어를 사용하세요.
# 구독 계정으로 로그인 (브라우저 OAuth)
$ claude

# API 키로 로그인하려면
$ claude auth login --console
⚠️ 로그인 완료 후 claude auth status 로 정상 연결됐는지 확인하세요.
5
설치 상태 점검 (선택)
문제가 있을 때 자동 진단해주는 명령어예요.
$ claude doctor
✅
여기까지 됐다면 준비 완료!
이제 아래 "설치 방법" 섹션에서 원하는 스킬을 골라 설치하시면 됩니다.
🚀 INSTALLATION GUIDE

설치 방법,
3가지 중 하나면 됩니다

Claude Code가 설치된 환경에서 진행하세요. 가장 빠른 건 방법 A — 명령어 한 줄이면 끝납니다.

1
터미널에서 명령어 실행
Claude Code CLI가 설치된 터미널을 열고 아래 명령어를 붙여넣으세요. 마켓플레이스를 등록(marketplace add)한 뒤 설치(plugin install)하는 2단계입니다.
# 예시: Marketing Skills 설치
$ claude plugin marketplace add coreyhaines31/marketingskills
$ claude plugin install marketing-skills@marketingskills

# Superpowers 설치
$ claude plugin marketplace add obra/superpowers
$ claude plugin install superpowers@superpowers-dev

# GitHub 저장소를 스킬로 바로 설치하고 싶다면 (marketplace 구조가 없는 경우)
$ npx skills add remotion-dev/skills -a claude-code -g -y
⚠️ 명령어는 claude-code가 아니라 claude로 시작합니다 (npm 패키지명과 실행 명령어가 다릅니다).
2
Claude Code 재시작
설치 후 Claude Code를 재시작하면 스킬이 자동으로 활성화됩니다. /skill-name으로 호출할 수 있어요.
+
💡 보너스 — 토큰 비용까지 줄이고 싶다면: rtk
스킬이 "어떻게 시키느냐"의 문제라면, rtk는 "얼마나 비용이 드느냐"의 문제를 해결하는 도구입니다. 명령어 출력(git status, 테스트 결과 등)이 그대로 모델 컨텍스트에 들어가는 걸 압축해서 넘겨주는 오픈소스 CLI 프록시예요. Claude Code, Cursor는 물론 Hermes도 공식 지원합니다.
# 설치 (macOS/Homebrew)
$ brew install rtk

# Claude Code / Copilot용 초기화
$ rtk init -g

# Hermes용 초기화
$ rtk init --agent hermes

# 설치 확인 + 절감량 대시보드
$ rtk --version
$ rtk gain
⚠️ 30분 코딩 세션 기준 11.8만 → 2.4만 토큰까지 줄었다는 주장이 있지만, 실제 절감 폭은 프로젝트·명령어 패턴마다 달라요. 도입 후 rtk gain으로 직접 측정해서 확인하는 걸 권장합니다. (GitHub ⭐74,000+, Apache 2.0 라이선스 · rtk-ai/rtk →)
🪟 Windows 버전 설치법
v0.37.2부터 네이티브 바이너리 훅으로 동작해서 Unix 셸(bash/jq) 없이도 CMD·PowerShell·Windows Terminal에서 바로 명령어가 자동으로 rtk로 치환돼요. 더블클릭 실행은 안 되고 반드시 터미널에서 실행해야 합니다.
# 1. GitHub Releases에서 rtk-x86_64-pc-windows-msvc.zip 다운로드 후 압축 해제
#    https://github.com/rtk-ai/rtk/releases

# 2. 압축 푼 rtk.exe를 PATH에 있는 폴더로 이동 (예: C:\Users\<내계정>\.local\bin)

# 3. 초기화 — 네이티브 바이너리 훅 설치 (Claude Code / Copilot)
$ rtk init -g

# Hermes용 초기화
$ rtk init --agent hermes

# 설치 확인
$ rtk --version
$ rtk gain
💡 일부 필터가 ripgrep(rg)을 필요로 해요 — 없으면 winget install BurntSushi.ripgrep.MSVC로 설치해두면 경고가 안 뜹니다. WSL 사용자는 macOS/Linux와 동일하게 curl -fsSL .../install.sh | sh 한 줄이면 됩니다.
1
GitHub에서 SKILL.md 파일 다운로드
원하는 스킬의 GitHub 저장소에서 SKILL.md 파일을 직접 다운로드합니다.
2
스킬 폴더에 저장
다운로드한 파일을 스킬 폴더에 저장합니다.
# 전체 적용 (홈 폴더)
~/.claude/skills/스킬이름/SKILL.md

# 프로젝트만 적용 (현재 폴더 내)
.claude/skills/스킬이름/SKILL.md
3
Claude Code 재시작 후 사용
/스킬이름 으로 바로 호출하세요. SKILL.md 안에 정의된 모든 커맨드가 활성화됩니다.
1
저장소 클론
스킬 컬렉션 전체를 한 번에 받아서 원하는 것만 골라 쓰는 방법입니다. 348개 스킬이 들어있는 컬렉션도 있어요.
$ git clone https://github.com/alirezarezvani/claude-skills
# ⭐ 23,000+ · 348개 스킬 모음집
2
원하는 스킬만 복사
클론된 폴더에서 원하는 스킬 디렉토리를 ~/.claude/skills/ 로 복사하면 됩니다.
$ cp -r claude-skills/marketing ~/.claude/skills/marketing
$ cp -r claude-skills/finance ~/.claude/skills/finance

🏢 TEAM SETUP

우리 팀 전체가
한 번에 설치하는 법

Claude Code는 조직 단위 클라우드 동기화가 없어서, 팀원 각자 로컬에 스크립트 한 번 돌리면 끝나는 방식이 가장 빠릅니다. 아래 스크립트는 이 페이지에서 소개한 스킬 12종을 전부 자동 설치합니다.

1
팀원 각자 터미널에서 한 줄 실행
Claude Code CLI가 이미 설치되어 있어야 합니다. 아래 명령어를 실행하면 marketing-skills, superpowers, ui-ux-design-pro 플러그인 + Design DNA, Web Animation, Three.js, Remotion, MengTo 종합 스킬, claude-mem, ruflo까지 전부 자동 설치됩니다.
# PowerShell에서 실행 (cmd가 아닌 PowerShell 창이어야 합니다)
$ irm https://yeaurpoong-think.github.io/claude-skills-guide/install-org-skills.ps1 | iex
⚠️ 실행이 차단되면 PowerShell을 관리자 권한으로 열고 Set-ExecutionPolicy RemoteSigned 실행 후 다시 시도하세요.
# SR바이오텍 조직 스킬 일괄 설치
$ curl -fsSL https://yeaurpoong-think.github.io/claude-skills-guide/install-org-skills.sh | bash
2
Claude Code 재시작
설치 후 Claude Code를 재시작하면 팀 전체가 동일한 스킬셋으로 작업할 수 있습니다. 새 팀원이 합류하면 이 페이지 링크만 보내주면 됩니다.
3
스크립트 직접 열어보기
설치 전에 무슨 명령이 실행되는지 확인하고 싶다면 스크립트 원문을 먼저 열어보세요.
$ curl -fsSL https://yeaurpoong-think.github.io/claude-skills-guide/install-org-skills.sh  # macOS/Linux용 원문
$ curl -fsSL https://yeaurpoong-think.github.io/claude-skills-guide/install-org-skills.ps1  # Windows PowerShell용 원문
❓ FAQ

자주 묻는 것들

Claude Skills는 현재 Claude Code(터미널 기반 AI 코딩 에이전트)에서 동작하는 기능입니다. claude.ai 웹 브라우저 버전에서는 직접 지원되지 않습니다. 단, Cursor나 Windsurf 같은 에디터에서도 같은 스킬 파일을 사용할 수 있어요.
skills.sh가 현재 가장 큰 Claude Skills 디렉토리입니다. GitHub에서 직접 검색하거나 커뮤니티 Discord/Reddit에서도 추천 스킬을 찾을 수 있어요.
일반적으로 충돌은 없습니다. 각 스킬은 독립적으로 작동하며 고유한 이름을 가집니다. 다만 두 스킬이 같은 슬래시 커맨드를 정의하면 나중에 설치된 것이 우선합니다.
네! SKILL.md 파일을 만들어 GitHub에 올리면 바로 배포됩니다. Anthropic 공식 문서에 스킬 작성 가이드가 있어요.
현재 대부분의 스킬은 오픈소스로 무료입니다. 일부 커머셜 도구(Remotion Pro 등)가 자체 스킬을 제공하지만, 스킬 자체는 무료로 제공되고 도구 구독이 별도로 필요할 수 있습니다.
